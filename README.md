# 🧩 MOSAIC Community Toolkit

> Automated workflows, shared schemas, and organizer tools for **Madison's Open Source & AI Communities (MOSAIC)**.

---

## 🎯 Vision

MOSAIC serves as an overarching non-profit umbrella connecting local developer groups across the Madison, WI region:
* **Cloud Native Madison (CNCF)**
* **Agentic AI Foundation (AAIF) Community Madison**
* **Google DevFest**
* **Madison Women in Tech**

This toolkit provides open-source infrastructure, automated scripts, and shared data schemas to streamline day-to-day organizer operations.
